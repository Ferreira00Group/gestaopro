# GestãoPRO v5.91.3

Ajuste visual da área de vencimentos na tela inicial.

## Novidades
- Cartões de vencimento com acabamento escuro e detalhes dourados, alinhados ao tema do GestãoPRO.
- Nome do cliente em destaque e valor da dívida visível.
- Rota do cliente exibida logo abaixo do nome; quando não houver rota cadastrada, isso fica explícito.
- Ações Receber e Cobrar compactas, mantendo área de toque confortável.
- Data, dias de atraso e classificação continuam agrupados no cabeçalho de cada vencimento.
- Mantida a atualização de navegação Android e saída com backup da versão 5.91.2.

## Publicação
Substitua os arquivos do projeto no GitHub pelo conteúdo deste pacote. A versão do app, as URLs com cache-busting e o cache do Service Worker foram atualizados para **5.91.3**.
